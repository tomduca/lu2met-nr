# Local Build Instructions

Use the maintained [BUILD.md](BUILD.md) guide for macOS and Windows build prerequisites and commands. It is the canonical build reference for this repository.

The Rust Python extension is located in `spectral_nr/`. The desktop and web audio frontends and their launch/build scripts are located in `audio_processor/`.
